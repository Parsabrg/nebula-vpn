Install Nebula VPN

Nebula VPN has apps for Android, Windows and Linux. All of them come from the latest release on GitHub, and all of them are free.

Android

  1. Open the latest release on the phone and download nebula-vpn-…-android-arm64.apk (almost every phone from the last eight years). If you are not sure, take the universal APK: it works on every phone.
  2. Open the file and allow installing from this source when Android asks.
  3. Open Nebula VPN. Updates are offered inside the app from then on, checked against the signed release.

Windows

  1. Download nebula-vpn-…-windows-x64-setup.exe and run it, or take the portable .zip if you cannot install programs.
  2. The first connection asks for administrator rights once: the VPN creates its own network adapter.
  3. The kill switch, start at sign-in and the tray icon are in Settings.

Linux

  1. Debian and Ubuntu: install the .deb with sudo apt install ./nebula-vpn-…-linux-x64.deb.
  2. Other distributions: the .AppImage runs as it is, or unpack the .tar.gz.
  3. Connecting asks for your password through polkit; the kill switch uses nftables.

Check the download

Every release has a SHA256SUMS.txt listing each file, signed by the release key in the repository (docs/release-signers). Windows and Linux files also carry GitHub build attestations: gh attestation verify <file> -R Parsabrg/nebula-vpn.

Connect

  • Your own server: choose "Connect to your server" and paste the address the installer printed, or the pairing link from the admin panel. See Run a server.
  • No server: Free mode starts with a public subscription of tested configurations, and takes any vless://, vmess://, trojan://, ss:// or hysteria2:// link or subscription you trust.
  • iPhone and iPad: there is no iOS app yet. In the Android or desktop app, make a subscription link (Account) and add it to Streisand, V2Box, Hiddify or FoXray.
Nebula VPN is free and open source. Not affiliated with Slack's or Defined Networking's Nebula overlay network.
