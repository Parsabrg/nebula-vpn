Run your own Nebula VPN server

One command on a fresh Ubuntu or Debian VPS sets up everything: the VPN protocols, the admin panel, accounts, backups and the certificate. It takes about 15 minutes; 2 GB of memory is enough.

Install

git clone https://github.com/Parsabrg/nebula-vpn nebula
cd nebula && sudo ./install.sh

It asks for a domain, the administrator's email, how to send email, and the administrator's password. Before it asks for the certificate it tells you the two DNS records to create. Everything else (Docker, keys, nginx, the firewall, Xray, Hysteria2, WireGuard, the VPN agent, daily encrypted backups) is done for you. Run it again at any time to change an answer; what is set up stays.

After installing

  • Accounts: there is no public sign-up. People request access, you approve in the admin panel, and they set a password from a single-use link. Device limits, expiry and per-device revocation are in the panel.
  • Protocols and ports: sudo ./install.sh --configure turns protocols on or off and changes their ports; the firewall and the apps follow.
  • Check every protocol: sudo python3 infrastructure/check-protocols.py connects through each one the way the app does.
  • Update: sudo ./install.sh --update moves to the newest release and lists what changed.
  • Backups: encrypted nightly; --restore <file> brings everything back on a new server.

A server in Iran and one abroad

When the server abroad is blocked or throttled from Iran, a second server inside Iran can forward to it: a relay. Add it in the admin panel (Server health → Relays); the panel shows the commands for the relay's server, and the relay reports in by itself. In the app it appears as one more server, for example "Germany via Tehran".

More servers

Server health → Add server gives a one-line install.sh --join command for each new machine. One admin panel manages them all.
