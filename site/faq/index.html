Nebula VPN FAQ

Is Nebula VPN the same as Slack's Nebula?

No. Slack's Nebula (by Defined Networking) is an overlay network for connecting servers. Nebula VPN is an unrelated, free, open-source VPN for getting past censorship, with Android, Windows and Linux apps.

Is Nebula VPN free?

Yes. The apps and the server are free and open source. You pay only for the VPS you run it on, or use Free mode with public configurations.

Does Nebula VPN work in Iran?

It is built for Iran first. It offers VLESS REALITY, XHTTP through Cloudflare, Hysteria2, a relay through a server inside Iran and a DNS tunnel, and it is tested on Iranian home and mobile networks for each release.

Is there an iPhone app?

Not yet. Make a subscription link in the app and add it to Streisand, V2Box, Hiddify or FoXray on the iPhone or iPad.

Does Nebula VPN keep logs?

No connection logs and no IP addresses are kept, and the web server keeps no access log. The privacy statement in the repository lists exactly what is stored.

Can I use it without my own server?

Yes: Free mode starts with a public subscription of tested configurations and accepts any vless, vmess, trojan, shadowsocks or hysteria2 link you trust.

Which protocol should I pick?

Start with Automatic. It tests the protocols on your network and shows which ones carry data. See the protocols page for what each one is good at.

Nebula VPN is free and open source. Not affiliated with Slack's or Defined Networking's Nebula overlay network.
