Nebula VPN

A free, open-source VPN for networks that filter and throttle, Iran first. Run your own server; the apps for Android, Windows and Linux find the protocol your network lets through and keep working when addresses are blocked.

Download Source code on GitHub

What it does

Many protocols

VLESS with REALITY, XHTTP, gRPC and WebSocket, VMess, Shadowsocks-2022, Hysteria2 and WireGuard. Automatic tests them on your network and picks one that carries data.

Gets past blocks

Reaches its server directly, through a Cloudflare route with ECH, or through a relay server, and learns new routes without an update.

DNS tunnel

A last resort when only DNS gets through: slow, but enough for messages. Works with your own lists of resolvers.

Free mode

No server? Add vless://, vmess://, trojan://, ss:// or hysteria2:// links and subscriptions you trust, and test them all.

iPhone and iPad

A subscription link for Streisand, V2Box, Hiddify or FoXray gives an account's servers to iOS apps.

Private by design

No connection logs, no IP addresses kept, no public sign-up. Signed releases with build attestations.

Get started

  1. Download the app for Android, Windows or Linux from the latest release.
  2. Pair it with your server's link, or use Free mode with links you trust.
  3. Tap Connect. To run your own server, follow the install guide.
